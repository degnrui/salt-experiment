# 教师课程空间重设计

## 目标

将教师端从单页看板升级为更适合课堂管理的课程空间，使教师能够先登录、再查看已有课程、快速创建新课程，并在课程详情中按小组查看实验设计记录和错误统计。

## 第一版范围

- 登录前只显示登录卡片，不暴露任何课程信息。
- 登录后进入课程空间首页。
- 课程空间以卡片网格展示已有课程。
- 最后一张卡片固定为“创建新课程”入口。
- 创建课程使用弹窗完成。
- 第一版仅提供 `食盐溶解实验` 这一种 simulation，但课程数据中保留 simulation 字段。
- 点击课程卡片进入课程详情。
- 课程详情展示班级总体统计、各组错误统计和提交记录。
- 每个小组支持展开与收拢。

## 页面结构

### 未登录状态

- 页面中央显示登录卡片。
- 登录成功前不显示课程卡片、课程数据或统计信息。

### 课程空间

- 使用卡片网格布局。
- 已有课程卡片展示：
  - 课程名称
  - simulation 名称
  - 小组数量
  - 创建时间
- 卡片网格末尾固定显示 `＋ 创建新课程`。
- 点击课程卡片进入对应课程详情。
- 点击创建卡片打开创建课程弹窗。

### 创建课程弹窗

- 字段：
  - 课程名称
  - 分组数量
  - simulation
- 第一版 simulation 选项仅有：
  - 食盐溶解实验
- 提交成功后关闭弹窗并刷新课程空间列表。

### 课程详情

- 顶部显示：
  - 返回课程空间
  - 课程名称
  - simulation 名称
- 班级总体统计：
  - 总提交数
  - 正确提交数
  - 正确率
  - 按探究任务统计
  - 全班错误类型统计
- 小组列表：
  - 每个小组一张折叠卡片
  - 收起态显示：小组名、小组码、错误总览
  - 展开态显示：
    - 该组按探究任务划分的错误统计
    - 中文提交记录表格

## 中文提交表格

列包括：

- 提交时间
- 探究任务
- A 杯设计
- B 杯设计
- 加盐时机
- 搅拌时机
- 判定结果
- 错误原因

### 字段中文化

- `stir` 显示为 `探究搅拌`
- `temp` 显示为 `探究温度`
- `size` 显示为 `探究颗粒`
- `cold` 显示为 `冷水`
- `hot` 显示为 `热水`
- `fine` 显示为 `细盐`
- `coarse` 显示为 `粗盐`
- `yes` 显示为 `是`
- `no` 显示为 `否`
- `same` 显示为 `同时`
- `diff` 显示为 `先后`

## 小组统计口径

小组层面不展示总提交数、正确次数、正确率。

小组层面仅展示：

- 按探究任务分类的错误类型次数
- 每种错误出现的次数

## 数据与接口调整

### Classroom 新增字段

- `simulation_type`

第一版固定使用 `salt_dissolution`。

### 课程列表接口

教师课程列表返回：

- `id`
- `name`
- `simulationType`
- `simulationLabel`
- `groupCount`
- `createdAt`

### 创建课程接口

创建课程时接收：

- `name`
- `groupCount`
- `simulationType`

### 课程详情接口

现有 dashboard 响应扩展：

- 课程 simulation 信息
- 每组错误统计
- 小组提交表格所需的中文化原始字段

## 交互细节

- 创建课程弹窗可关闭。
- 小组卡片默认收起。
- 一个课程详情页中允许多个小组同时展开。
- 教师端保留轮询刷新，但刷新时不应强制关闭已展开的小组。

## 异常处理

- 登录失败时停留在登录页并提示错误。
- 创建课程缺少名称或分组数量非法时阻止提交。
- dashboard 拉取失败时保留当前页面并提示刷新失败。
- 若课程还没有提交记录，统计区域显示零值，小组表格显示暂无提交。

## 测试重点

- 未登录教师无法读取课程数据。
- 课程创建可保存 simulation 字段。
- 课程列表正确返回小组数量和 simulation 标签。
- dashboard 正确返回每组错误统计。
- 中文表格渲染所需字段完整。
- 轮询刷新后仍能保留当前展开的小组集合。
